Aggregate analytics privacy

This public site uses the same canonical-host-only, DNT/GPC-respecting aggregate analytics design documented by AI Playgrounds. The project code sends only aggregate page/event paths. It does not send experiment values, query strings, referrer URLs, names, email addresses, student responses, or a project tracking identifier. Ordinary network metadata reaches the analytics server; see the AI Playgrounds analytics specification for the exact boundary.
